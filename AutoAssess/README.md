**自动测评助手**

AutoAssess 面向文字型心理、性格自评与练习页面，提供从题目读取、偏好选择、填写核对到继续下一题的自动化流程。它由 **Windows 桌面窗口 + Chrome/Edge 扩展**组成：桌面负责配置和运行控制，扩展负责与当前页面交互，网页中不再显示助手浮窗。

不需要模型 API、云端推理服务或远程题库。选择依据可以查看，已有作答会被保留，遇到无法确认的结构会停止并说明原因。

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动填写 / 手动辅助 | 可连续处理已支持题型，也可先查看结果，再确认填写当前题目 |
| 桌面统一控制 | “作答、偏好设置、页面适配、连接”四个页面，集中查看题目、结果、计数和运行状态 |
| 完整偏好配置 | 预设、自定义五项倾向、策略、描述排序、个人答案、停留时间与自动继续 |
| 同页多题与分页 | 先检查题组，保留已有答案；回读选中状态后再继续 |
| 本机配对 | 随机端口与临时连接码，固定绑定用户选中的标签页，不自动跟随其他页面 |
| 运行状态保护 | 暂停、继续、停止、过期结果作废、命令去重与连接失效处理 |
| 系统托盘 | 齿轮图标，双击恢复窗口，右键停止或退出；托盘异常时保留可访问的窗口入口 |
| 内置练习 | 220 道性格练习题、200 条精确量表规则，以及原创交互结构样例 |

## 快速开始

### 环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 2004 或更新版本；桌面托盘与窗口采集属性依赖 Windows |
| 浏览器 | 支持 Manifest V3 的 Chrome 或 Edge |
| 桌面运行环境 | Python 3.10+，包含 `tkinter` 和 `pythonw.exe` |
| 开发与验证 | Node.js 20+、Python 3.10+；普通使用不需要 Node.js |

桌面程序只使用 Python 标准库，不需要安装 PyQt。启动脚本会检查已有 Python 环境，不会自动安装依赖或修改执行策略。

### 1. 获取项目

```bash
git clone https://github.com/hxhxhxhy1226/qw.git autoassess
cd autoassess/AutoAssess
```

也可以下载仓库 ZIP 后解压，进入 `AutoAssess` 文件夹。保留其中的 `assessment-plugin` 与 `desktop-companion` 两个目录。

### 2. 加载浏览器扩展

在 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions` 中开启开发者模式，选择“加载已解压的扩展程序”，选中 **`assessment-plugin`** 目录。

### 3. 启动桌面窗口

双击 [desktop-companion/启动桌面助手.cmd](desktop-companion/启动桌面助手.cmd)。打开桌面的“连接”页，复制连接码。

### 4. 连接当前页面

打开要处理的页面，在浏览器工具栏点击 AutoAssess，将连接码粘贴到“桌面窗口”，点击“连接当前页面”。成功后，桌面会显示连接页面及当前配置。

建议先打开扩展中的**内置练习**，使用“手动辅助”核对识别和填写结果，再启用自动填写。

### 5. 保存偏好并开始

在桌面“偏好设置”中选择策略、停留时间和自动继续，点击“保存配置”，等待浏览器确认后开始。

**关闭桌面窗口会收起到托盘，任务可以继续运行。** 要停止并退出，请使用托盘右键菜单中的“退出”。更新项目后，应退出旧桌面程序、重新加载扩展，再重新配对。

## 题型支持

支持以**可确认的文字与控件结构**为前提，不以平台名称或选项数量直接认定题型。

| 交互 | 当前范围 |
| --- | --- |
| 符合程度、认同程度、频率量表 | 2–7 级明确文字标签，支持倒序、重排和已标注反向题 |
| 是非自述、偏好二选一 | 具有明确个人自评或主观偏好语义的题目 |
| 描述单选 | 最符合、最不像等文字自述 |
| 双角色迫选 | 三选二、四选二等 2–8 项描述，分别选择 Most / Least，保证两项不同 |
| 同页多题 | 可分组的量表、描述题与迫选题，逐未答题处理 |
| 文字矩阵 | 可确认表头与行列关系的单选量表矩阵 |
| DISC / SHL 结构样例 | 已实现特定四选二表格及 M/L 三选二公开示例结构 |

原生 radio、ARIA、常见组件库、问卷星样式及部分公开观察到的选择器结构有相应适配。图片人格题、拖拽全排序、任意复杂合并表格、跨域 iframe 和未确认的分步迫选流程尚不支持。

## 离线选择如何工作

规则优先级为：**个人精确答案 → 已标注量表题 → 完整描述排序 → 当前策略**。

| 策略 | 行为 |
| --- | --- |
| 积极 | 按本地词组与当前倾向比较；依据不足时注明并使用稳定随机回退 |
| 平衡 | 适度收敛描述倾向，量表选择更接近中间的等级 |
| 随机 | 在合法选项中稳定选择；同题、同配置保持一致 |
| 严格匹配 | 无精确规则或完整排序时停止，等待补充 |

性格自评没有统一正确答案。内置规则不能完整理解任意文本，随机回退也不等于语义识别成功；项目不输出人格诊断、官方 MBTI/DISC 分数或岗位适配结论。需要审阅未知题时，使用“严格匹配”或“手动辅助”。

## 数据与窗口行为

题目计算在本机完成。桌面服务仅监听 `127.0.0.1` 的随机端口，使用本次进程的配对令牌；题面与结果保存在内存中，不写入常规日志。浏览器偏好保存在扩展存储中，连接令牌保存在扩展会话存储中。

桌面可设置并回读 Windows 原生窗口采集排除属性。**“采集排除已设置”表示属性匹配，不表示所有截图、录屏软件均已验证。** 它只作用于桌面主窗口，不覆盖其他程序窗口、浏览器工具栏或实体相机拍摄，也不代表网页平台无法识别自动化。托盘图标是否进入折叠区由 Windows 管理。

最终提交仍由用户处理。混入个人信息、知识题或不支持控件的页面可能停止，等待人工核对。

## 项目结构

```text
.
├── assessment-plugin/      # 浏览器扩展、离线规则、题库与 JavaScript 测试
├── desktop-companion/      # Windows 桌面界面、本机服务、托盘与 Python 测试
├── docs/                   # 使用与架构文档
├── tools/                  # 统一验证与发布构建
└── README.md
```

源码目录保持固定，版本变化由 Git 记录。构建产物写入 `dist/`，不需要复制多个带版本号的源码目录。

## 开发与验证

在项目根目录执行：

```bash
python tools/verify.py
python tools/build_release.py
```

验证覆盖离线规则、配置校验、桌面控制状态、命令去重、失败恢复、本机 HTTP 协议、配置回读和托盘逻辑。桌面窗口渲染、真实托盘交互及具体截图/录屏工具的输出仍需在实际 Windows 环境中验收；模拟原生 API 的测试不能替代这些检查。

新增页面适配时，请同时提供最小复现、预期动作和原创或有明确来源的结构样例。开发接口与数据流见 [架构说明](docs/architecture.md)，日常操作及排查见 [使用指南](docs/usage.md)。

## 来源与许可

练习题包括原有 100 道性格题和从 `rubynor/bigfive-web` 固定提交导入的 120 道中文 IPIP 题项。对应 200 条精确量表规则保留了维度、正反向与来源信息。

项目也参考了公开的迫选、矩阵和表格控件结构。参考交互不等于导入其题库，也不代表通过商业平台官方验收。来源、固定提交和使用范围见 [第三方声明](assessment-plugin/THIRD_PARTY_NOTICES.md)，数据格式见 [题库说明](assessment-plugin/QUESTION_BANK_SCHEMA.md)。

当前仓库**尚未为项目整体指定统一许可证**。中文 IPIP 120 项的派生文件保留上游 MIT 声明，IPIP 原题项另有 public-domain 来源说明；随附许可位于 [vendor](assessment-plugin/vendor)。

原有 100 题保留各自 `provenance`：其中 24 题标注为自编，另外 76 题来自外部公开来源，现有材料中的再分发授权仍待核实。因此不能把全部 220 题统一视为原创、MIT 或 public domain；具体来源与授权状态以 [第三方声明](assessment-plugin/THIRD_PARTY_NOTICES.md) 为准。
