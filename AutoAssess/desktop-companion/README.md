# 离线性格助手桌面窗口 v0.5.1

这个组件使用 Python 标准库 tkinter、ctypes 和 HTTP 服务，不需要安装 PyQt，不修改 Chrome 配置或 Windows 注册表。

1. 双击 `启动桌面助手.cmd`。它直接寻找带 tkinter 的 Python，再用 pythonw 打开窗口，**不需要修改 PowerShell 执行策略，也不会自动安装软件包**。若进程启动后立即退出，控制台显示错误并提示检查 `startup-error.log`。`start.ps1` 仅作为已有 PowerShell 脚本运行环境中的可选入口。
2. 在“连接”页检查窗口采集排除状态，并复制连接码。
3. 在浏览器扩展工具栏中粘贴连接码，连接当前测评标签页。
4. 在“作答”页查看题目与结果，底部固定开始、暂停、停止与填写按钮。“偏好设置”包含运行方式、停留时间、自动继续、性格预设、五项倾向、策略、排序与个人答案；“页面适配”包含全部七项选择器。保存后等待浏览器确认，未保存的编辑不会被同步覆盖。

网页浮窗已取消，扩展弹窗只保留桌面配对与内置练习入口。修改倾向或排序会自动切换到自定义偏好；无效配置会显示原因，不能作为已保存状态。

连接码仅在本次桌面进程存活期间有效，服务只监听 `127.0.0.1` 的随机端口。HTTP 请求需要连接码里的令牌；不提供远程网络监听、任意脚本、文件或命令执行接口。题面和结果只保存在内存，不写入日志。

采集排除针对桌面主窗口的真正顶层 HWND 设置 `WDA_EXCLUDEFROMCAPTURE`，然后回读验证，支持 Windows 10 2004 或更高版本。状态“已设置”只表示系统属性匹配，**不代表所有截图或录屏软件都排除该窗口**。若设置失败，会保留错误提示；在要求采集排除但尚未验证时，开始和填写按钮保持禁用。如果此时已有运行或等待执行的任务，会排入停止命令并取消其余待执行命令，不以禁用按钮替代停止。用户可以关闭这项设置后使用普通桌面窗口。

窗口按“作答、偏好设置、页面适配、连接”四页签组织，初始尺寸随屏幕收缩，内容区可滚动。

托盘采用自绘齿轮图标，名称提示为“离线性格助手”。托盘成功启用后，关闭或最小化窗口会收起到托盘，任务继续运行；双击图标恢复，右键可停止或退出。退出会请求停止并关闭服务。Windows 决定图标在通知区还是折叠区，本程序不改通知图标策略，也不保证指定折叠位置。托盘失败时保留或恢复任务栏与窗口入口，不会把窗口藏到无法找回。

连接超过 6 秒未收到心跳时，窗口清除旧题及旧配置显示并禁用控制。请以扩展回执为准，不把命令已发送当作执行完成。

测试命令（不启动图形窗口）：

```powershell
python -B -m unittest discover -s desktop-companion/tests -v
```

`main.py --smoke-report <文件>` 会短暂打开真实 Windows 窗口并记录采集属性回读，然后退出。此命令需要图形执行许可；属性记录仍不是截图、录屏验收。
