# 离线性格测评助手 v0.5.1

浏览器扩展按已保存的个人偏好处理文字自评、量表和迫选题，支持手动辅助、自动填写、暂停、停止和填写核对。所有题目计算在本机完成，不需要模型、密钥或外部推理服务。

本版将控制和配置集中到 Windows 桌面窗口，网页浮窗已取消。扩展负责与选中的标签页配对、读取题目和执行填写；弹窗提供桌面配对与内置练习入口。

## 安装与使用

1. 在 Chrome 或 Edge 扩展管理页开启开发者模式，加载本目录 `assessment-plugin`，确认版本为 **0.5.1**。
2. 双击同级目录中的 `desktop-companion/启动桌面助手.cmd`，在“连接”页检查窗口状态并复制连接码。需要 Windows 10 2004+、带 tkinter 的 Python 3.10+。
3. 打开要处理的页面，在扩展弹窗中粘贴连接码并点击“连接当前页面”。连接固定到该标签页。
4. 在桌面的“偏好设置”和“页面适配”中修改配置，保存后等待浏览器确认，再开始运行。建议先用内置练习和手动辅助核对行为。
5. 托盘启用后关闭或最小化窗口会收起；双击齿轮图标恢复，使用托盘右键菜单退出。更新时先退出旧桌面程序、重新加载扩展，再重新配对。

桌面服务只监听 `127.0.0.1` 的随机端口，连接码随进程启动重新生成。题面与结果只保存在内存中，最终提交由用户处理。

完整使用步骤、支持范围及故障排查见 [使用指南](../docs/usage.md)，桌面运行要求见 [桌面说明](../desktop-companion/README.md)。发布包由项目根目录的 `python tools/build_release.py` 生成，位于 `dist/autoassess-v0.5.1.zip`。

## 交互与选择依据

支持具有明确文字语义及可确认控件的 2–7 级量表、是非自述、偏好二选一、描述单选、双角色迫选、同页多题和文字矩阵。DISC 四选二与 SHL 三选二支持已实现的具体结构；平台名称不代表所有页面均已验收。图片人格题、拖拽全排序、任意复杂表格和跨域 iframe 尚不支持。详细题型范围见 [项目首页](../README.md#题型支持)。

离线规则优先级为：个人精确答案 → 已标注量表题 → 完整描述排序 → 当前策略。积极与平衡策略在描述依据不足时会注明稳定随机回退；严格匹配会停止并等待补充。性格自评没有统一正确答案，本地规则不输出人格诊断、官方 MBTI/DISC 分数或岗位适配结论。

桌面的窗口采集属性只作用于自己的顶层窗口。“采集排除已设置”表示 Windows 属性回读匹配，不表示所有截图或录屏软件均已验收。托盘位置由 Windows 管理。

## 题库与来源

活动题库共 **220 题**：原有 100 道性格题，以及从 `rubynor/bigfive-web` 固定提交导入的 120 道中文 IPIP 题项，共 **200 条**精确量表规则。原始题文、来源维度、正反向标记、分面信息及选项说明均保留。

来源、固定提交、许可及已导入/仅参考范围见 [第三方声明](THIRD_PARTY_NOTICES.md)，维护方法见 [题库说明](QUESTION_BANK_SCHEMA.md)。开发仓库保留 `vendor/bigfive-source/` 的原始快照，测试与转换器使用这些固定文件。

## 开发与验证

在项目根目录运行：

```powershell
python tools/verify.py
python tools/build_release.py
```

统一验证覆盖 JavaScript 规则与页面控制、桌面 Python 配置与状态、托盘逻辑、真实本机 HTTP 联调和两份题库校验。日志与报告写入 `build/verification/`。源码保持固定目录，由 Git 记录版本。

这些检查不启动真实浏览器、桌面窗口或托盘，实际布局、托盘交互及具体截图/录屏工具输出仍需在 Windows 环境中验收。实现细节见 [开发说明](PLUGIN_DEVELOPMENT.md) 和 [架构说明](../docs/architecture.md)。
