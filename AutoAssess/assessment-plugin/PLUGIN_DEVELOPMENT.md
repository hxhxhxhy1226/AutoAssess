# v0.5.1 开发说明

本版采用桌面专用控制方式。浏览器不再挂载助手浮窗，`content.js` 的分离状态节点只服务于原有识别/填写状态机，`show-panel`、网页配置入口和自动展示行为均已停用。扩展更新时清理旧版遗留浮窗，控制器按版本去重，防止重复注入。

`popup.js` 只处理桌面配对、连接状态、断开和内置练习入口。`loader.js` 只恢复原本绑定的桌面会话。内置练习页加载与普通页面相同的配置校验模块，并通过可信的扩展页面来源发送心跳。

`desktop-settings.js` 定义桌面配置白名单：运行方式、停留时间、自动继续、预设、策略、五轴倾向、描述排序、个人答案和七项选择器。`desktop-bridge.js` 通过 connect/exchange 顶层 settings 同步配置，仅在变化时发送；配置命令先验证结构，再由内容控制器通过现有 P.config 和 CSS 语法检查保存。保存成功后作废旧识别结果，下一次回读将浏览器实际配置反馈给桌面。旧桌面缺少 settings 能力标记时拒绝绑定。

桌面 `settings_model.py` 对同一数据结构严格验证，HTTP 总请求限制为512KiB。`BridgeState` 保存配置及 revision；未保存的编辑不会被每次心跳覆盖，保存回执和配置回读共同完成确认，换绑定或断开清理旧配置。配置只在停止状态修改。题面仍只在内存中传递，令牌不进入配置表。

`main.py` 按作答、偏好设置、页面适配、连接四页签组织，偏好内分常用/排序/个人答案。预设显示真实生效的倾向；编辑倾向或排序会自动选择custom。常用操作固定，长内容滚动。所有配置控件和原生采集排除状态都位于桌面主窗口。

`tray.py` 使用标准 Shell_NotifyIconW、独立消息线程和Tk主线程事件队列，提供打开/停止/退出。gear.ico 为自绘多尺寸中性齿轮，提示名称为离线性格助手。托盘成功后才把主窗口改成工具窗口并支持收起；失败时恢复任务栏和窗口。Explorer重启后重加图标，多次丢失/恢复均更新状态。程序不修改Windows通知图标折叠策略，也不伪装其他程序身份。

`capture.py` 仍对自己的顶层窗口设置并回读WDA_EXCLUDEFROMCAPTURE。托盘与窗口样式变化后重设属性。属性成功不等于所有截图/录屏软件已验收；托盘菜单和其他程序窗口不属于主窗口属性范围。

在项目根目录运行 `python tools/verify.py`，覆盖现有离线规则、桌面专用控制器、配置、桥、弹窗、Python HTTP/配置/托盘及真实 Python/JavaScript 本机联调。结果写入 `build/verification/`，发布使用 `python tools/build_release.py` 输出到 `dist/`。旧网页浮窗专用 UI 测试已从当前桌面专用套件退役。

统一验证不启动真实窗口与托盘，实际画面、托盘交互和采集输出需另行实机验收。模拟原生 API 测试、窗口结构代码或回环网络联调不代表实际画面和托盘位置已验收。
