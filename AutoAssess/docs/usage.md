# AutoAssess 使用指南

[返回项目首页](../README.md)

## 安装与配对

AutoAssess 由浏览器扩展和 Windows 桌面程序共同工作。扩展目录为 `assessment-plugin`，桌面目录为 `desktop-companion`。

1. 在 Chrome/Edge 的扩展管理页加载解压后的 `assessment-plugin`。
2. 双击 `desktop-companion/启动桌面助手.cmd`。需要包含 tkinter 的 Python；启动失败时，终端会显示原因，桌面目录的 `startup-error.log` 记录启动异常。
3. 在桌面“连接”页复制连接码。
4. 切到需要处理的网页，打开扩展工具栏，粘贴连接码并点击“连接当前页面”。

配对码在桌面程序重新启动后会改变。连接只绑定当时选中的标签页；切换浏览器标签不会把任务自动转移过去。需要更换目标时，先断开，再在新的页面重新连接。

首次使用建议从扩展的内置练习开始。这里提供原创控件结构样例，可先确认题目是否完整识别、选择方向是否正确，以及是否保留了已有答案。

## 桌面四个页面

| 页面 | 用途 |
| --- | --- |
| 作答 | 查看当前题目、选择结果、依据、计数与倒计时；开始、暂停、继续、停止或填写本题 |
| 偏好设置 | 运行方式、停留时间、自动继续、性格预设、五项倾向、策略、描述排序与个人答案 |
| 页面适配 | 七项 CSS 选择器；通常留空，使用内置结构识别 |
| 连接 | 配对码、窗口置顶、采集属性状态、托盘与退出操作 |

网页中不显示助手浮窗。浏览器工具栏只负责配对、状态和练习入口，配置统一在桌面窗口维护。

## 选择运行方式

**手动辅助**先生成离线选择和依据。核对后点击“仅填写本题”；进入下一题后可再次识别。它适合首次检查一个页面或复核未知题。

**自动填写**会读取题目、生成选择、填写并回读选中状态。开启“自动继续”后，程序在停留时间结束、当前页已识别题组完成且导航控件可确认时继续下一题或下一页。

“暂停”保留本次状态和剩余停留时间；“继续”接着运行。“停止”结束本次运行并作废待用结果。若要修改配置，应先**停止**，保存并等待确认后再开始。

最终交卷、提交及未支持的页面步骤由用户完成。不要把填写计数当作整份问卷已提交的证明。

## 配置保存与生效

桌面配置由浏览器回读确认。点击“保存配置”后，等待提示“配置已与浏览器同步”；请求已发送不等于已保存。保存失败时会保留原因，未保存的编辑不会被普通心跳同步覆盖。

修改五项倾向或描述排序会自动使用“自定义偏好”。预设模式显示对应预设的倾向；个人答案和答题策略可与预设共同使用。

### 五项倾向

| 字段 | 含义 |
| --- | --- |
| E | 外向沟通 |
| A | 合作体谅 |
| C | 条理尽责 |
| S | 情绪稳定 |
| O | 开放探索 |

每项使用 1–5 的整数。它们是本项目偏好规则使用的输入，不是测评诊断结果，也不能直接等同于 MBTI 或 DISC 的维度。

### 描述排序

每行一组，从最符合到最不符合。同一优先级的别名可用 `|` 分隔：

```text
有计划性的|有计划的
善于合作的|团队合作
喜欢主动交流的
```

编辑排序后会切换为自定义偏好。需要完整匹配的迫选题会据此取最前与最后的描述；空项、重复词或不足以覆盖当前题目时，按规则提示或转入所选策略。

### 个人答案

格式为 `完整题干 => 选项文字`，每行一题：

```text
我喜欢提前安排任务。 => 比较符合
```

这是用户指定的个人选择，不是标准答案库。匹配按文字进行；已指定答案却无法唯一定位选项时，程序会停止并提示修正。

## 策略与未知题

积极、平衡和随机策略可对合法题型继续生成选择。其中，文本依据不足时可能使用**稳定随机**回退，并在结果中注明；这不代表已理解题意或获得正确答案。

严格匹配不会以未知题的词组或随机回退强行继续。希望逐题复核时，选择“严格匹配”或“手动辅助”。

## 页面适配

先保持所有选择器为空。只有自动识别无法确认范围时，再提供对应结构。CSS 语法须有效；题目容器应限定当前题组。

| 配置 | 作用 |
| --- | --- |
| 题目容器 | 当前题组的外层元素 |
| 容器内题干 | 题干文字范围 |
| 可点击选项 | 每个可选择的选项元素 |
| 下一题按钮 | 当前题目或页面的下一步控件 |
| 迫选描述行 / 卡片 | 双角色题中的描述单元 |
| 最符合控件 | 相应描述的 Most 选择控件 |
| 最不符合控件 | 相应描述的 Least 选择控件 |

自定义选择器不会取消题型语义、已有答案、选中状态和导航校验。不支持的知识题、图片、排序或混合页面仍可能被拒绝。

## 托盘、收起与退出

托盘正常时，关闭或最小化桌面窗口会收起到齿轮图标，**不会自动停止任务**。双击图标重新打开窗口，右键菜单可停止本次运行或退出程序。

Windows 决定图标显示在通知区域还是折叠区。托盘初始化失败或失效时，程序保留或恢复窗口入口。若只是希望结束当前运行，点击“停止”；若要结束程序，使用“退出”。

## 窗口采集属性

“窗口采集排除”针对桌面主窗口设置 Windows 原生属性，并回读是否匹配。请求保护但未生效时，程序不会把它显示为已设置；已有或待执行的任务会请求停止。

属性匹配不能保证所有截图、录屏软件都会排除该窗口。浏览器工具栏、其他程序窗口、托盘菜单和实体相机不属于桌面主窗口的保护范围。该属性也不改变网页平台对页面事件的记录。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 桌面程序没有启动 | 检查 Python 是否包含 tkinter 和 pythonw；查看终端提示与启动异常日志 |
| 连接码无效或过期 | 确认桌面程序仍在运行，重新复制本次进程的完整连接码 |
| 提示桌面版本不兼容 | 扩展与桌面程序使用同一份项目；退出旧程序、重新加载扩展，再启动并配对 |
| 配置没有生效 | 先停止任务，保存配置，等待浏览器确认；倾向与排序编辑应使用自定义偏好 |
| 识别结果是“稳定随机” | 当前描述依据不足；改用严格匹配、手动辅助或补充个人规则 |
| 同页有些题目未填写 | 检查是否已有答案、混入不支持题型，或题组范围无法确认；查看停止原因 |
| 窗口关闭后任务仍在运行 | 关闭会收起到托盘；用托盘菜单“停止本次运行”或“退出”结束 |
| 仍看到旧网页浮窗 | 重新加载扩展，确认当前版本；退出重复运行的旧桌面程序，再配对 |

排查问题时，优先提供浏览器与系统版本、控件结构、操作步骤和经过脱敏的最小样例。不要公开连接码、账户资料或无关页面内容。
